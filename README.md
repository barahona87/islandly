# Islandly

La isla dinámica, ahora en tu Mac: música con carátula, animación de carga, isla dividida, bandeja de archivos con
AirDrop, selector de color, indicadores de cámara y micrófono, y más. Gratis, privada y ligera.

**Página y descarga:** https://barahona87.github.io/islandly/

- Requisitos: macOS 14 Sonoma o posterior, Mac con Apple silicon o Intel.
- La primera vez, macOS dice que no puede comprobar la app: Configuración del Sistema → Privacidad y seguridad →
  **Abrir igualmente**.

Este repositorio contiene solo la página web y los instaladores publicados.
